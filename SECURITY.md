# Security reporting

Report vulnerabilities privately using **Report a vulnerability** on this
repository's [Security tab](https://github.com/alexcatdad/ci-actions/security).

Include the affected workflow/action and commit, the relevant event and runner
type, the expected permission boundary, and a minimal synthetic reproduction.
Do not include real credentials, private caller code or production data.

Reports about checkout, cache credentials, registry publication and deployment
authorization should identify which boundary could be crossed. Use synthetic
resources when reproducing an issue.
